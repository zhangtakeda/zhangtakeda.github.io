概念导读 · 13

网格不仅是坐标，也是离散算子的一部分

网格不是背景图片，而是参考坐标到物理坐标的数值映射；其 Jacobian 直接参与积分、梯度和守恒，因此几何质量属于离散算子的一部分。

01 · 问题对象

计算域的离散几何与运动表示

结构/非结构网格、ALE、level set 和 cut-cell 分别以不同方式描述坐标、移动界面和拓扑变化。

02 · 基本思路

控制映射可逆性和几何误差

detJ>0 保证单元不翻转，κ2(J) 衡量局部拉伸，几何守恒律保证移动网格不会凭空制造常量变化。

03 · 关键进展

从静态直角网格到曲边、移动和保守重映射

高阶曲边单元准确表示边界；ALE 将网格速度纳入方程；level set 允许界面拓扑改变；保守 remap 保持总量。

04 · 适用边界

X 点坐标退化与拓扑事件

单一磁通坐标在 separatrix/X 点处会退化；平滑网格也可能具有负 Jacobian 或极高条件数。

方法脉络

这些方法分别解决什么问题

曲线/等参映射

曲线或等参映射把复杂物理单元拉回统一参考单元，标准基函数和求积规则因此可以复用，但仍需监测 Jacobian。

ALE

ALE 显式引入网格速度并满足几何守恒律，在纯 Euler 与纯 Lagrange 描述之间调节网格运动和畸变。

Level set / cut-cell / remap

Level set 和 cut-cell 允许界面跨越固定网格，保守 remap 则在重网格时传递总量，适合大形变和拓扑变化。

聚变语境

聚变模拟中的位置

自由边界平衡和边缘区域网格应在积分点监控最小归一化 Jacobian 与最大 κ2(J)，并为 X 点采用多块、非磁通坐标或嵌入式表示。

处理对象

计算域、曲线坐标、移动界面和自由边界

典型输入

CAD/边界、尺寸场、拓扑、几何运动和目标分辨率

典型输出

体/面网格、映射 Jacobian、界面表示和保守重映射

先检查

网格是否随时间移动；拓扑会否改变；X 点/尖角处坐标是否退化

经典

结构网格、椭圆网格生成、isoparametric 单元和网格平滑。

成熟

Delaunay/前沿法、各向异性自适应、ALE、level set、phase-field 和浸入边界。

现代

高阶曲边网格、cut-cell、保守 remap、自动拓扑事件和可微几何。

物理单元由参考映射定义

x=ΦK(ξ),JK=∂x∂ξ,detJK(ξ)>0.

长宽比只是质量的一部分。高阶曲边单元应在积分点检查 Jacobian 符号、条件数、最小角和解的各向异性方向。负 Jacobian 表示单元翻转，积分和基函数映射失去意义。[Gmsh]

ALE 把网格速度显式写入守恒律

∂(Ju)∂t|χ+∇ξ⋅[JFALE(u;v−w)]=JS(u),∂J∂t|χ=J∇⋅w.

这里 J=det(∂x/∂ξ)，w 是网格速度。对不可压缩标量输运，常见的物理坐标简写为 ∂tu|χ+(v−w)⋅∇u=L(u)，但一般守恒系统必须连同映射 Jacobian 和几何守恒律一起离散。ALE 在 Euler 与 Lagrange 描述之间选择网格运动；level set 适合拓扑变化，phase-field 用有限厚度层，immersed/cut-cell 在背景网格嵌入边界。 [ALE] [Level set]

重映射必须守恒

∑K′|K′|u¯K′=∑K|K|u¯K.

网格重构后不能仅靠节点插值传输守恒量；应使用交叠体积、有限体积 remap 或受约束投影。X 点附近磁通坐标 Jacobian 退化，通常需要多块、非磁通坐标或局部拓扑处理。

常见失效模式
  • 只检查初始网格质量，不监视推进后的翻转和几何守恒律。
  • 在 X 点附近强制单一光滑磁通坐标。
  • 自适应重网格后用普通插值转移密度/能量，破坏全局守恒。
工程判据

逐步监控 Jacobian、条件数、几何误差和重映射守恒；在拓扑变化/X 点附近采用适合的多块或嵌入表示。
